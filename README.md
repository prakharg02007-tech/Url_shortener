# 🔗 URL Shortener

A full-stack URL Shortener Web Application that converts long URLs into short, easy-to-share links.

The application is built using **React.js** for the frontend and **Node.js + Express.js** for the backend, with **MongoDB** used for storing shortened URLs.

---

## 🚀 Features

- 🔗 Convert long URLs into short URLs
- ⚡ Generate unique short URL codes using Nanoid
- 💾 Store URLs in MongoDB
- 🔍 Check whether a URL already exists before creating a new short URL
- ↪️ Automatically redirect users to the original URL
- ⏳ Automatically expire stored URLs using MongoDB TTL
- 🎨 Interactive frontend with animated OGL wave background
- 📱 Responsive user interface
- 🌐 REST API based backend
- 🔐 CORS enabled for frontend-backend communication
